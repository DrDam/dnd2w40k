    Conversions

    Voici les correspondances entre les termes utilisés dans D&D 5e et leurs équivalents dans 40k5e.

    Alignement

    Les alignements restent inchangés par rapport à la version originale de D&D 5e. On trouve donc le Bien, le Mal, l’Ordre, le Chaos, ainsi que des alignements neutres entre ces extrêmes. Le Chaos ne signifie pas que la créature vénère des aspects du Chaos ou des Puissances Ruineuses, mais plutôt qu’elle n’adhère strictement à aucune loi ni à aucun code moral.

    Types de créatures

    Types de créatures supprimés. Les limons, les géants et les dragons ont tous été supprimés.

    Types de créatures modifiés. À des fins de conversion, les célestes, les fées et les démons ont été transformés en daemons.
